# Contributing

Thanks for your interest in contributing to **SVG Spritesheet → CSS**! Here's how to get started.

## Development setup

```bash
git clone https://github.com/CameronFoxly/SVGSpritesheet-to-CSS.git
cd SVGSpritesheet-to-CSS
npm install
npm run dev
```

## Making changes

1. **Fork** the repo and create a branch from `main`.
2. Make your changes — keep commits focused and descriptive.
3. Run linting and build before pushing:
   ```bash
   npm run lint
   npm run build
   ```
4. Open a **pull request** against `main` with a clear description of what changed and why.

## Guidelines

- Write TypeScript; use functional React components.
- Keep PRs small and focused on a single change when possible.
- If adding a feature, update the README to document it.

## Reporting bugs

Open a [GitHub Issue](https://github.com/CameronFoxly/SVGSpritesheet-to-CSS/issues) with:

- Steps to reproduce
- Expected vs. actual behavior
- Browser/OS if relevant

## Feature requests

Feature ideas are welcome as issues too — please label them with **enhancement**.
